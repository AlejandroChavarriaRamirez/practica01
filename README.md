## Cómo ejecutarlo

1. En MySQL Workbench, conectado como root, correr el script `sql/practica.sql`. Ahí se crea la base `practica`, el usuario `usuario_practica` (clave `la_Clave`) y la tabla con unos datos de prueba.
2. Abrir la carpeta `practica01` en NetBeans.
3. Hacer Clean and Build y luego Run (MySQL tiene que estar encendido).
4. Entrar a http://localhost:91
